# Archived Data Files

These files were archived on 2026-10-05 because they were never loaded by the game and caused confusion (workers kept prototyping against them).

- **events.json** — Old event-system draft. Never loaded.
- **trials.json** — Old ability-trial draft. Never loaded.
- **shop.json** — Galactic shop concept. No shop system exists in code. Never loaded.
- **systemMessages.json** — Superseded by inline System dialogue. Never loaded.
- **villagers.json** — 6 hand-authored villagers (Mara, Jesse, Aki, Ruth, Theo, Priya). Loaded but never spawned. The game uses 12 randomly generated villagers per run (see background_survivors.json + characterGen.json).

Do not restore without verifying the game actually loads and uses the file.
