# Evidence — prog-meta: cross-run achievement codex (2026-10-10)

## What was built
`src/js/metaProgression.js` — META PROGRESSION, a persistent cross-run achievement codex ("Records"), per Steve's 2026-10-10 directive. Self-attaching module (Object.assign(Game, methods) + defensive wraps), loads after `statusEffects.js` in index.html (after progression.js, as briefed).

## Design
- **45 achievements as data** (`{id, name, desc, hint}`), 9 categories: Flora 🌿 (4), Fauna 🐾 (4), Monsters 👹 (6), The Escalation 📈 (5), The Show 📺 (5), The Long Haul ◈ (3), The Table 🌌 (8: table + 6 frames + final choice), Sickness 🤒 (5), Milestones ⭐ (5).
- **"All" tiers are data-driven**: counted against `Game.data` at check time (45 plants / 48 animals / 30 monsters today), never hardcoded.
- **Persistence**: localStorage `oversight.meta.v1`, write-through JSON. Corrupt data → key reset, never throws. Never touches save-game slots.
- **Hooks** (all defensive: absent method skipped silently, every hook exception-guarded): `identifyPlant`, `_noteAnimalDepth`, `ensureMonsterEntry` (+wave), `monsterNamingCheck`, `recordWaveKill`, `unlockedWave` (max-seen, resets on new run), `arcBeat`, `noteCrisis`, `contestLearn`, `_contestEnd`, `_showEnd`, `_contestDie`, `tableScene`, `chooseTableOption` (pre-capture, it clears tableChoices), `recordLegend`, `checkSystemArrival`, `applyStatus`/`cureStatus` (gated on truthy return — resisted applications don't count; scholar-only).
- **Disease canon respected**: mundane (6) vs alien (9) pools from docs/DISEASES.md, never mixed.
- **UI**: title-screen "🏆 Records" button + `recordsScreen()` in app.js. Summary line (n/45) on one screen; category-grouped list scrolls (long-term planning surface). Unmet = ??? + vague hint; hints verified to leak no true monster/plant/animal ids. Unlock toast: `🏆 {name} — {desc}` via Game.toast, guarded.
- **Zero gameplay leakage**: meta methods are store-only. Proven by test (below).
