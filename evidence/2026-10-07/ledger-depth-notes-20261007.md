   dimensions (might, brokerage, showmanship, embrace, defiance, exposed,
   protected, killed, betrayed, foodShared, foodHoarded). Each threshold fires
   once per run. Kinds: gossip / show / system / lived / witness.
2. **Knowledge gating** — `_beatGate(kind)`: gossip always (overhearing IS the
   channel; the first gossip beat marks `selfTalkedAbout` with framing),
   show needs viewership ≥ 12 or a seen broadcast, system needs
   `integrationStage() >= 1`, lived/witness always. Failed gates queue in
   `pg.ledgerQueue`; `flushLedgerBeats()` (every endDay) fires them when the
   world catches up — beats land late, not never.

   `hearsAboutSelf()`. Before that: "They describe someone who sounds like
   you — but the name hasn't reached you yet." You hear the SHAPE before the name.
4. **Unity state machine** — `unityState()` resolves unified−fractured to
   as-one / close-knit / holding / fraying / fractured. `_checkUnityTransition()`
   walks every tier crossed, direction-aware (`worse`/`better` texts per tier).
   Always visible — you live it.
5. **Food truth** — new `foodHoarded` ledger dimension (backfilled for old saves).
   `foodStance()` → sharer/even/hoarder; transitions narrated with social
   consequences ("That silence has a price.").

   `exposeBribery` wrap on success: names the briber/bought/amount when case
   data is at hand, deliberate generic nouns ("The one who paid…") when not.
