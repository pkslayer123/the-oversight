# Game Ontology Ledger

**The single source of truth for how The Oversight works.**

This is not a manual doc. It's validated against the code by `scripts/validate-ontology.js`.
Releases are blocked if the ledger doesn't match reality.

## How it works

1. Every system file (`src/js/*.js`) declares an `@ontology` header block
2. The validator parses headers and checks them against the actual code
3. `scripts/bump-sw-version.sh` runs the validator — release fails if invalid

## Header format

```js
// @ontology
// system: contests
// description: Alien TV contests and shows that interrupt village life
// provides:
//   - contestEligible() -> {eligible, reason}
//   - contestTick() -> event|null
//   - fireContest(contest)
//   - resolveContest()
// rules:
//   - unlock_day: 14 (code: contestTick, contestEligible)
//   - weekly_budget: 2 (code: contestTick)
//   - daily_chance: 0.3 (code: contestTick)
//   - contest_vs_show: 0.6 (code: contestTick)
// consumes:
//   - scholar.day
//   - state.showBudget
```

## Validation rules

- Every `src/js/*.js` file must have an `@ontology` block
- Every function in `provides` must exist in the file
- Every rule must cite its `code:` location
- Every `consumes` entry must be a real state path or function
