# ROADMAP

## Vertical slice 1 — "Seven Days" (first playable)

Goal: prove the survival loop is fun before any System layer exists.

- Title screen (terminal aesthetic) → new game → home biome pick (Southeast woodlands only for slice 1)
- Village hub (static for slice 1: pantry, scholar select with 2 pre-made villagers, Codex viewer)
- One region, one 7x7 tile grid, fog of war, 7 in-game days
- Day loop: 4 AP, Forage / Rest / Treat Water / Explore actions
- Real plant data: ~10 Southeast woodland edibles with seasons
- Hunger/hydration/energy stats, calorie math, spoilage (simple)
- One hostile encounter (simple turn-based: 3 actions/round, telegraphed intent, flee option)
- Win slice: survive 7 days. Lose slice: starve or die.
- PWA: manifest, service worker (offline), installable, iOS home-screen ready

## Slice 2 — Village lives

- Expedition clock drives village sim (pantry drains, morale, events)
- Return/death → village → next scholar loop
- Codex persistence across scholars
- 3 villagers with backstories + ability kits

## Slice 3 — The Integration

- Day 8: the sky changes. System UI fades in over survival UI.
- Levels, trials, ability offers (pick 1 of 3)
- First alien flora alongside real plants

## Later

- Region node map + travel legs; PNW + Southwest desert biomes
- Parties (up to 3), Monster Codex, mentorship
- Seasons/year, winter boss, campaign win, endless mode
- Capacitor wrap for App Store
